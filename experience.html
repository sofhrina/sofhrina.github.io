Aug – Sep 2026
Jinan, China

Algorithm Engineering Intern · Inspur Intelligent Technology

I worked across database migration, computer-vision data operations and multimodal-model evaluation. For a highway-tolling system, I mapped seven business scenarios to database schemas, programmatically checked 280 field mappings with zero errors, and migrated 47 SQL queries across eight scenarios from SQLite to GaussDB.

I also governed three vision datasets: more than 2,000 detection boxes, 1,359 redacted sensitive regions across 190 images, and 16 Python tools for parsing, IoU comparison, consistency checks, anomaly detection and annotation. A pixel-level rule removed the manual step for 600 fixed-position boxes. In a separate model audit, I classified seven recurring error patterns across roughly 40 multimodal outputs and traced the observed failures to downstream generation.

Database280 mappings checked and 47 queries migrated; validation was static because database access was unavailable.
Vision dataThree governed datasets, 2,000+ boxes and 1,359 privacy redactions.
Tooling16 Python utilities for repeatable QA, comparison, visualisation and annotation.

Jun – Aug 2026
Jinan, China

Front-end Development Intern · Inspur Yunzhou Industrial Internet

I developed the employee-facing front end of a three-role enterprise cafeteria ordering mini-program, covering search, cart and preorder flows, pickup codes, order tracking, reviews, likes and favourites. I refactored the ordering workflow around consistent API fields, vendor-level grouping, preserved price precision, synchronised lifecycle states and submission locks against duplicate orders.

I extended the product beyond the client with persistent interaction state and a Node.js/Express endpoint using JWT authentication, input validation, duplicate-action prevention and ownership checks. I then consolidated styles across 105 files into reusable design tokens and added skeleton states plus homepage and search caching.

Quality358 Jest tests across 16 suites for services, permissions, state and core workflows.
DeliveryAbout 5,200 lines of code across 13 feature commits and four pull requests.
IntegrationCompleted a 33-file cross-branch integration while preserving the end-to-end order flow.
